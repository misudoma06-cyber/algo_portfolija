# Algo portfelj

Aplikacija za spremljanje trgov, zaznavanje režimov (uptrend / downtrend / range)
in vklapljanje strategij, ki imajo v danem režimu edge.

- `app.py` – aplikacija (Streamlit)
- `settings.json` – privzeti trgi in vklopljene strategije
- `engine/` – podatki, režimi, backtest, test naključnih trejdov
- `engine/strategies/` – knjižnica strategij
